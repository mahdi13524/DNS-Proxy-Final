# DNS Batch Tester

## هدف
آزمایش حداکثر ۱۰ دامنه در یک درخواست داشبورد، با نمایش نتیجه مستقل هر دامنه.

## رفتار
- کاربر در رابط داشبورد هر دامنه را در یک خط وارد می‌کند.
- `POST /api/batch` دامنه‌ها را به ترتیب و از طریق همان Resolver اصلی بررسی می‌کند.
- هر نتیجه شامل دامنه، منبع پاسخ، وضعیت، IP، TTL، زمان پاسخ و Decision X-Ray است.
- خطای اعتبارسنجی یک دامنه، اجرای دامنه‌های دیگر را متوقف نمی‌کند.
- نتایج با `via='batch'` در آمار واقعی Resolver ثبت می‌شوند.
- بعد از اجرای Batch، آمار و Top 5 Domains داشبورد Refresh می‌شوند.
- حداکثر ۱۰ دامنه در هر اجرا پذیرفته می‌شود.

## ایمنی و محدودیت
- Batch از Resolver اصلی استفاده می‌کند؛ بنابراین درخواست‌های معتبر ممکن است به Upstream واقعی ارسال شوند.
- درخواست‌ها ترتیبی اجرا می‌شوند، نه هم‌زمان.
- هیچ تنظیمی، فهرست فیلترینگ یا Cache به‌صورت ویژه توسط Batch تغییر داده نمی‌شود؛ رفتار عادی Resolver (از جمله Cache و فیلترینگ) حفظ می‌شود.
- ورودی نامعتبر به‌صورت `INVALID_INPUT` در همان ردیف نمایش داده می‌شود.
