# DNS Health Check

## هدف
پنل سبک بررسی سلامت اجزای اصلی داشبورد DNS Proxy؛ بدون تغییر تنظیمات یا وضعیت سرویس.

## موارد بررسی‌شده
- DNS Proxy: با پاسخ‌گویی API آمار (`/api/stats`) سنجیده می‌شود.
- Upstream: با endpoint موجود `/api/health` بررسی می‌شود؛ این endpoint یک query سلامت به `example.com` می‌فرستد.
- Cache: وضعیت فعال/غیرفعال و تعداد رکوردها از snapshot واقعی Resolver خوانده می‌شود.
- Configuration: مقادیر تنظیمات بارگذاری‌شده از نظر وجود IP، محدوده پورت و timeout و مقادیر Boolean بررسی می‌شوند.

## نکات رفتاری
- هیچ تنظیمی تغییر داده نمی‌شود.
- Cache پاک یا دست‌کاری نمی‌شود.
- بررسی سلامت Proxy از طریق همان API داشبورد انجام می‌شود.
- غیرفعال بودن Cache به‌عنوان هشدار نمایش داده می‌شود، نه خرابی DNS.
- نتیجه Upstream وابسته به دسترسی شبکه و پاسخ DNS در زمان بررسی است.
