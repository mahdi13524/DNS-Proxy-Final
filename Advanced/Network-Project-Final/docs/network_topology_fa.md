# نقشه توپولوژی شبکه DNS Proxy

## هدف
نمایش معماری اجزای اصلی DNS Proxy در داشبورد Advanced.

## اجزا
- Client: مبدأ درخواست DNS
- DNS Proxy: ورودی HTTP داشبورد و DNS UDP محلی
- Policy Engine: اعتبارسنجی دامنه و اجرای سیاست‌ها
- Ad Block: پاسخ محلی Sinkhole برای دامنه‌های فهرست تبلیغات
- Sanction: پاسخ محلی Proxy IP برای دامنه‌های فهرست تحریم
- DNS Cache: ذخیره پاسخ موفق با TTL
- Upstream DNS: DNS واقعی یا شبیه‌ساز UDP طبق تنظیمات فعلی

## رفتار نمایش
- حالت Upstream، مقصد IP:Port، وضعیت فیلترینگ، وضعیت Cache و آخرین رویداد از پاسخ `/api/stats` خوانده می‌شوند.
- کلیک روی هر گره، توضیح همان جزء را نمایش می‌دهد.
- هیچ درخواست DNS اضافی برای ترسیم توپولوژی ارسال نمی‌شود.
- خطوط، مسیر منطقی معماری را نشان می‌دهند و capture واقعی بسته‌های شبکه نیستند.

## محدودیت
وضعیت Upstream تا پیش از اولین درخواست، «هنوز درخواست نشده» نمایش داده می‌شود؛ بنابراین توپولوژی سلامت سرور را بدون انجام درخواست شبکه حدس نمی‌زند.
